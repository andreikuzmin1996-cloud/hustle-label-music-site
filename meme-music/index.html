Добавить YouTube-канал

Нужен ID канала, который начинается с UC (не @ник). RSS работает без ключа YouTube API, но не гарантирует полную историю или тренды всей платформы.

Подключённые каналы

TikTok, VK и Instagram: автоматический импорт из этих платформ пока не подключён. Можно добавлять ссылки на видео вручную.
Как найти ID YouTube-канала?

Открой канал YouTube → «О канале» → «Поделиться» → «Копировать ID канала» (если доступно). Либо используй ссылку вида youtube.com/channel/UC...
